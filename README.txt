ALFIYA & DANISH — REFINED WEDDING INVITATION

This version uses the supplied A&D monogram, inspired by the deep-teal, antique-gold and blush floral invitation artwork.

Features:
• A&D logo on the opening screen and a subtle watermark throughout the page.
• Redesigned editorial invitation copy and a more ornate deep-teal / champagne-gold look.
• Distinct Haldi, Mehendi and Nikah colour palettes.
• On tapping OPEN INVITATION, the requested YouTube track (video ID nu1C6tcSvOQ) is embedded and autoplay is requested. The browser may still block autoplay depending on device/browser settings; this is initiated directly by the tap.
• Embedded Google Maps previews and Google Maps directions links for both addresses.
• Existing family names, parent details, dates, prayer timings and venues are retained.

To publish:
1. Upload/replace index.html and the assets folder at the root of AlfiyaMukadam/wedding_invitation.
2. Commit to the main branch.
3. Wait for GitHub Pages build and deployment to complete.
4. Refresh https://alfiyamukadam.github.io/wedding_invitation/

Important:
• Keep the assets folder beside index.html; the logo is loaded from assets/AD-monogram.png.
• YouTube playback requires an internet connection and the video owner must permit embedding. If embedding is disabled, the browser cannot play it inside the page.
• For exact Google Maps pins, replace address searches with the official Google Maps share links for each venue.
